# Common Ground — prototype

A broker-led transaction workspace exploring connections among current owners, tenants and future buyers, investors, and lending professionals.

## Explore
Open `index.html` in a desktop browser. The application is self-contained; no installation or backend is required.

## Included
- Resident-to-owner transition planning
- Direct purchase and mortgage-assumption comparisons
- Investor lending and property-acquisition economics
- Owner proceeds and retained-property comparisons
- Lender-condition tracking and shared feasibility review

## Scope
Illustrative concept only. Fictional opportunities and partners. Rates and expenses are assumptions, not quotes. No financing approval, transaction recommendation, verified listing, or live matching service. Independent concept; not affiliated with Zegacy. See REVIEW.md for model limits.

Edits are stored in the visitor's browser. They are not synchronized, uploaded to GitHub, or shared with other visitors. Do not enter sensitive household information.

## GitHub Pages
Publish the main branch from the repository root using GitHub Pages. `index.html` is the complete application.
